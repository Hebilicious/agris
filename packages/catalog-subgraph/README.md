# @agris/catalog-subgraph

The catalog subgraph: the Federation `Item` entity, localized item names, and item-name search over the generated search artifact. `.` exports the subgraph; `./catalog`, `./catalog-search-artifact`, `./item-name-search` and `./generated-catalog-search-artifact` export its parts.

`tools/catalog` generates `src/generated-catalog-search-artifact.ts`; do not edit it by hand.
