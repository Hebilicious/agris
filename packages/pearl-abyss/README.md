# @agris/pearl-abyss

The typed Pearl Abyss Central Market client: request builders, response codecs, models, region and locale descriptors, item IDs, and the transport and in-flight coordination the market Worker runs.

| Export      | Contents                                                                   |
| ----------- | -------------------------------------------------------------------------- |
| `.`         | protocol: codecs, models, requests, categories, regions, locales, item IDs |
| `./regions` | region descriptors                                                         |
| `./locales` | item locale descriptors                                                    |
| `./item-id` | item ID validation                                                         |
| `./server`  | the protocol plus the transport machine and in-flight coordinator          |
