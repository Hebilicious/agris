# @agris/market-worker

The Agris market subgraph Worker. It serves the market subgraph through its `BudgetedMarketSubgraph` entrypoint and coordinates every Pearl Abyss call through the `PearlAbyssCoordinator` Durable Object, one per upstream host, each created with the location hint of the server it calls.

`src/market.ts` holds the subgraph and the coordination, independent of their host; `PearlAbyssCoordinatorObject` is the coordinator's work, and it always asks the deployment's one allowance object for permits. `src/index.ts` exports `default`, `BudgetedMarketSubgraph`, `PearlAbyssCoordinator` and the bindings they read (`MarketEnv`); `PA_RATE_LIMITER` is optional, and absent sets no rate limit. `PA_MAX_CONCURRENT_REQUESTS` is optional too: absent or `0` sets no concurrency limit of its own, and a coordinator then runs at most `UNLIMITED_CONCURRENT_PEARL_ABYSS_REQUESTS` (1,000) distinct requests at once. Deploy it with the `enable_request_signal` compatibility flag, as the stack does, so a caller that gives up takes its read out of the coordinator's queue. The `PA_COORDINATOR` namespace holds one coordinator per Pearl Abyss host and one more, `PEARL_ABYSS_ALLOWANCE_ADDRESS`, that alone consults `PA_RATE_LIMITER` for the whole deployment. The smoke stage in `infra/src/smoke/` deploys `src/index.ts` as a host would, and the Workers runtime evidence in `tests/` runs its bundle.
